매장용 주문 프린터 - 빠른 시작
==============================
1. 프린터 드라이버 설치 → 프린터를 USB 로 연결하고 전원 켜기.
2. FestivalReceipt-Setup.exe 실행 → 설치.
   ("Windows의 PC 보호" 창이 나오면: 추가 정보 → 실행)
   설치 없이 쓰려면 Portable.zip 압축 풀고 FestivalReceipt.exe 실행.
3. 처음 설정: 가게 이름 → 프린터 선택 + [테스트 인쇄] → PIN(숫자 4자리) 두 번 → 예시/빈 메뉴.
4. 판매:
   메뉴 버튼 또는 숫자키(1~9, 0=10번, F1~F12) → 오른쪽 주문 내역에 담김 (다시 누르면 +1)
   + / - : 선택 줄 수량,  Delete : 줄 삭제,  Esc : 전체 취소
   Enter → 미리보기 → Enter : 영수증 인쇄 + 판매 기록
5. 메뉴 바꾸기: [메뉴 관리] → PIN → 수정 → 초록색 [저장 (적용)] 꼭 누르기.
6. 가게 이름·프린터·백업 폴더: [설정] → PIN.
7. 마감: [오늘 매출 출력]. 판매 기록(엑셀): 탐색기 주소창에 %APPDATA%\FestivalReceipt 입력 → sales 폴더.
8. PIN 을 잊으면: 프로그램 종료 → %APPDATA%\FestivalReceipt\admin.json 삭제 → 다시 실행.

※ 주문 영수증(주문서) 전용입니다. 카드 결제/현금영수증/세금계산서가 아닙니다.
