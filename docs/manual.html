1. 소개와 추천 용도

매장용 주문 프린터는 노트북에 영수증 프린터를 연결해, 메뉴 버튼(또는 숫자 키)만 누르면 주문 영수증을 바로 출력하는 프로그램입니다. 인터넷이 없어도 모든 기능이 동작합니다.

  • 지역 축제·먹거리 장터의 음식 매대
  • 플리마켓, 팝업 스토어, 학교·교회 바자회 등 임시 매장
  • 주문서(주방 전달용) · 번호표 · 교환권 출력
  • 품목별 하루 매출 집계
주의: 이 프로그램이 출력하는 것은 주문 영수증(주문서)입니다. 카드 결제 단말기나 세금계산서/현금영수증을 대신하지 않습니다. 결제와 세금 신고는 별도의 결제 단말기·POS 를 사용하세요.

2. 준비물

항목내용

영수증 프린터신화포스 SLK-TS100 등 ESC/POS 방식 감열 영수증 프린터 (80mm 또는 58mm 용지)
라벨 프린터 (선택)Windows 드라이버가 있는 라벨 프린터 또는 일반 프린터 (79mm 연속 롤지도 지원)
프린터 드라이버제조사 홈페이지 또는 동봉 CD 에서 설치. 프로그램보다 먼저 설치하고 USB 로 연결하세요.
용지감열지(영수증 롤) 또는 라벨 용지

3. 내려받기와 설치

배포 페이지(GitHub Releases)에서 두 가지 중 하나를 내려받습니다.

파일설명
FestivalReceipt-Setup.exe
(설치용, 권장)		더블클릭 → 다음 → 설치. 바탕 화면과 시작 메뉴에 "매장용 주문 프린터" 바로가기가 생깁니다. 데이터는 %APPDATA%\FestivalReceipt 에 저장됩니다.
FestivalReceipt-Portable.zip
(포터블)		설치 없이 사용. 압축을 풀고 FestivalReceipt.exe 실행. 같은 폴더의 data 폴더에 설정과 판매 기록이 저장되므로 USB 에 넣어 다른 노트북에서도 그대로 쓸 수 있습니다. data 폴더를 지우지 마세요.

"Windows의 PC 보호" 창이 나올 때 (SmartScreen)

새로 배포된 프로그램이라 처음 실행할 때 파란색 경고 창이 나올 수 있습니다.

  1. 창의 추가 정보 글자를 누릅니다.
  2. 아래에 생긴 실행 버튼을 누릅니다.

한 번 실행하면 다음부터는 나오지 않습니다. 공식 배포 페이지에서 받은 파일만 실행하세요.

4. 처음 설정 (마법사)

처음 실행하면 4단계 "처음 설정" 창이 열립니다. [다음 ▶]으로 진행하세요.

① 가게 이름

영수증 맨 위에 인쇄될 가게(행사) 이름과, 필요하면 매대 이름을 입력합니다.

② 프린터 선택과 테스트 인쇄

목록에서 프린터를 고르고 [테스트 인쇄]를 눌러 한글이 바르게 나오는지 확인합니다. SLK-TS100 같은 영수증 프린터는 방식 "영수증 프린터(ESC/POS)", 용지 80mm(또는 58mm)로 둡니다.

③ 관리자 PIN

메뉴 관리와 설정을 열 때 쓰는 숫자 4자리 PIN 을 두 번 입력합니다. 직원이 메뉴·가격을 바꾸지 못하게 보호합니다.

④ 메뉴 시작

"예시 메뉴"(떡볶이, 어묵 등 — 나중에 수정)로 시작하거나, "빈 메뉴"로 시작해 바로 메뉴를 입력합니다. [완료]를 누르면 판매 화면이 열립니다.

5. 주문 받기

메뉴 담기

  • 메뉴 버튼을 누르거나 키보드 단축키를 누르면 오른쪽 주문 내역에 담깁니다. 같은 메뉴를 다시 누르면 수량이 1 늘어납니다.
  • 단축키: 1~9 = 1~9번, 0 = 10번, F1~F12 = 1~12번, Shift+F1/F2 = 13/14번. 버튼에 [ ] 로 표시되어 있습니다. (오른쪽 숫자 키패드도 됩니다)
  • 왼쪽 위 담는 수량을 바꾸면 한 번 누를 때 그 수만큼 담깁니다 (예: 단체 주문).

수량 고치기·지우기

하고 싶은 일방법
선택한 줄 수량 +1 / -1+ / - 키 또는 주문 내역 아래 [＋] [－] (0 이 되면 줄 삭제). 선택이 없으면 마지막 줄
선택한 줄 삭제Delete 키 또는 [줄 삭제]
주문 전체 취소Esc / Backspace 또는 [전체 취소] → 확인

결제·인쇄

  1. Enter 또는 초록색 [결제 / 인쇄]를 누릅니다.
  2. 미리보기 창에서 내용을 확인하고 Enter(인쇄)를 누르면 영수증이 출력되고 판매가 기록됩니다. 주문 내역은 비워집니다.
  3. Esc(취소)를 누르면 아무것도 기록되지 않고 영수증 번호도 그대로입니다.
영수증 번호는 매일 0001 부터 시작합니다. 위쪽 "출력 프린터" 체크로 이번에 출력할 프린터를 고를 수 있습니다 (둘 다 체크하면 영수증과 라벨 동시 출력).
인쇄가 실패하면 원인(프린터 이름 오류, 전원/USB, 용지 없음 등)이 알림창으로 나옵니다. "예"를 누르면 영수증을 파일로 저장하고 판매를 기록, "아니오"면 기록하지 않습니다. 프린터가 두 대일 때 한 대라도 출력되면 판매가 기록됩니다.

6. 메뉴 관리와 PIN

오른쪽 위 [메뉴 관리] → PIN 입력.

버튼기능
수정 적용목록에서 고른 줄의 품목/가격을 아래 입력칸 내용으로 바꿉니다.
추가"새 메뉴" 줄을 만들고 바로 선택합니다. 이름·가격 입력 후 [수정 적용].
삭제 / ▲ 위로 / ▼ 아래로줄 삭제, 순서 변경 (순서 = 단축키 번호, 자동 재지정)
저장 (적용)반드시 눌러야 판매 화면에 반영됩니다. 저장 안 한 변경이 있으면 창 제목에 "● 저장 안 된 변경 있음"이 표시되고, 닫을 때 "저장할까요?"(예/아니오/취소)를 묻습니다.
PIN 변경현재 PIN 확인 후 새 PIN(숫자 4자리) 두 번 입력
  • 가격은 0보다 큰 숫자, 이름은 비울 수 없습니다. 이전 메뉴는 자동으로 백업(menu.csv.bak_날짜시각)됩니다.
  • 메뉴를 바꿔도 지난 판매 기록은 바뀌지 않습니다.
  • PIN 을 5번 틀리면 60초 동안 잠깁니다.

7. 설정

오른쪽 위 [설정] → PIN 입력. [저장]하면 바로 적용됩니다 (다시 시작할 필요 없음).

가게 정보

  • 가게/행사 이름, 매대 이름, 하단 문구: 영수증에 인쇄되는 글자
  • 기기 ID: 노트북 여러 대를 쓸 때 구분용 (영문/숫자, 비우면 컴퓨터 이름)
  • 인쇄 전 미리보기: 끄면 Enter 한 번으로 바로 인쇄
  • 백업 폴더: [찾아보기…]로 USB 메모리 등 다른 드라이브를 고르면 판매마다 그곳에도 복사됩니다 (노트북 고장 대비)

프린터

항목선택
프린터Windows 에 설치된 프린터 목록에서 선택
방식영수증 프린터(ESC/POS): SLK-TS100 등 감열 영수증 프린터 (빠르고 자동 절단)
일반/라벨 프린터(Windows 드라이버): 라벨 프린터, 일반 프린터 등 드라이버가 있는 모든 프린터
레이아웃영수증 전체 / 라벨(크게 요약): 가게 이름·품목·수량·합계·번호만 크게
용지 폭80mm(한 줄 42칸) · 58mm(32칸) · 79mm 롤(연속 감열 롤지, 길이 자동) · 자동(드라이버에 설정한 라벨 크기)
사용 / 별명사용 체크 = 시작할 때 출력 대상. 별명 = 화면에 보이는 이름
라벨 크기 설정: Windows 설정 → 블루투스 및 장치 → 프린터 및 스캐너 → 라벨 프린터 → 인쇄 기본 설정 → 용지(Stock)에서 실제 라벨 크기(예: 50×30mm)와 간격(Gap) 또는 연속 용지를 고르세요. 프로그램이 용지 크기에 맞게 글자 크기를 자동 조절하고, 넘치면 여러 장으로 나눕니다.

8. 매출 확인과 판매 파일

  • [오늘 매출 출력]: 오늘 품목별 수량·금액 합계와 영수증 건수를 미리보기 후 인쇄합니다. 마감 정산에 쓰세요.
  • 판매 기록 파일: 데이터 폴더의 sales\2026-10-14.csv 처럼 날짜별 파일. 엑셀로 바로 열립니다 (품목마다 한 줄, 같은 주문은 같은 번호).
  • 데이터 폴더 열기: 탐색기 주소창에 %APPDATA%\FestivalReceipt 입력 후 Enter (포터블은 exe 옆 data 폴더).

9. 온라인 동기화 (선택)

여러 매대의 매출을 본부에서 실시간으로 보고 싶을 때 Google Firebase 로 판매 내역을 전송할 수 있습니다. 필요 없으면 꺼두세요 — 꺼도 모든 기능이 동작합니다.

  • [설정] → 온라인 동기화 탭에서 사용 체크, API 키·프로젝트 ID·전용 계정 이메일/비밀번호 입력.
  • 인터넷이 끊겨도 판매는 저장되고, 연결되면 자동 전송됩니다 (중복 없음). 화면 아래에 "동기화 완료 / 전송 대기 N건 / 오프라인" 표시.
  • Firebase 프로젝트 만드는 방법은 함께 제공되는 README.txt 의 7번 항목을 참고하세요 (담당자/개발자용).

10. 업데이트와 제거

  • 업데이트: 새 버전의 Setup.exe 를 그냥 실행해 덮어 설치하면 됩니다. 설정·메뉴·판매 기록은 그대로 유지됩니다. (포터블은 exe 파일만 새 것으로 교체)
  • 아주 예전 버전(프로그램 폴더에 config.json 이 있던 버전)에서 바꾸면 첫 실행 때 설정·메뉴·판매 기록을 자동으로 옮겨옵니다.
  • 제거: Windows 설정 → 앱 → "매장용 주문 프린터" → 제거 (또는 시작 메뉴의 제거). 판매 기록은 지워지지 않습니다. 완전히 지우려면 %APPDATA%\FestivalReceipt 폴더를 직접 삭제하세요 (먼저 백업!).

11. 문제 해결

증상해결 방법
한글이 깨져서(이상한 문자) 나옴영수증 프린터 방식(ESC/POS)에서 발생. 프린터 제조사 유틸리티에서 코드페이지/국가를 한국어(KS5601/CP949)로 설정. 그래도 안 되면 그 프린터의 방식을 "일반/라벨 프린터(Windows 드라이버)"로 바꿔 보세요.
아무것도 인쇄되지 않음① 프린터 전원·USB·용지 확인 ② [설정]→프린터의 [테스트 인쇄] ③ Windows "프린터 및 스캐너"에서 대기열에 멈춘 문서 삭제, "프린터 일시 중지" 해제 ④ 노트북 재시작
"프린터 이름이 잘못되었습니다"[설정]→프린터에서 목록의 프린터를 다시 선택하세요 (드라이버를 다시 설치하면 이름이 바뀔 수 있음, 예: "SLK-TS100 (사본 1)").
"오프라인" / "용지 없음"USB 를 다시 꽂고 전원을 켠 뒤 다시 인쇄. 용지 덮개가 닫혔는지 확인.
라벨 글자가 너무 작거나 잘림프린터 "인쇄 기본 설정"의 용지 크기가 실제 라벨과 같은지 확인. 79mm 롤이면 [설정]에서 용지 폭을 "79mm 롤"로.
영수증 폭이 맞지 않음58mm 용지면 [설정]→프린터→용지 폭 58mm.
PIN 을 잊어버림프로그램 종료 → %APPDATA%\FestivalReceipt\admin.json 파일 삭제 → 다시 실행 후 [메뉴 관리]를 열면 새 PIN 설정. (메뉴·판매 기록은 그대로)
백신이 차단/삭제함공식 배포 페이지에서 받은 파일이면 백신의 "예외(허용)"에 FestivalReceipt.exe 를 추가하세요. 새 프로그램이라 오진하는 경우가 있습니다.
"PC 보호" 창3장 참고: 추가 정보 → 실행
메뉴를 바꿨는데 화면이 그대로메뉴 관리에서 초록색 [저장 (적용)]을 눌렀는지 확인.

12. 자주 묻는 질문

Q. 인터넷이 꼭 필요한가요?
A. 아니요. 온라인 동기화를 쓰지 않으면 인터넷 없이 모든 기능이 동작합니다.

Q. 카드 결제나 현금영수증도 되나요?
A. 아니요. 주문 영수증(주문서) 출력 전용입니다. 결제는 별도 단말기를 쓰세요.

Q. 노트북 여러 대로 같이 팔아도 되나요?
A. 네. 각 노트북에 설치하고 [설정]에서 기기 ID 를 다르게(예: 1번매대, 2번매대) 정하세요. 매출은 노트북별로 저장됩니다.

Q. 영수증 프린터와 라벨 프린터를 동시에 쓸 수 있나요?
A. 네. 두 프린터를 등록하고 판매 화면 위쪽에서 둘 다 체크하면 한 번에 둘 다 출력됩니다.

Q. 갑자기 전원이 꺼지면 기록이 사라지나요?
A. 판매마다 즉시 디스크에 저장하므로 확정된 판매는 남습니다. USB 백업 폴더를 지정하면 더 안전합니다.

Q. 메뉴는 몇 개까지 되나요?
A. 제한은 없지만 단축키는 14번까지입니다. 그 이후 메뉴는 버튼으로 누르세요.

Q. 마우스 없이 쓸 수 있나요?
A. 네. 숫자키로 담고 Enter 두 번이면 인쇄됩니다.
